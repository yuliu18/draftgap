# personal-draft

Personal fork of DraftGap (vigovlugt/draftgap, MIT) for one player: draft suggestions weighted by the
player's own match history, read from the League client, with an optional LLM explanation layer.
Branch: `feat/personal-draft`. Upstream stays mergeable: new code lives in new files where possible.

## Specs

- S1. Personalization. User: "si mejor que esté a full personalizado a mi". Chosen option: "Estadística + explicación con LLM" — "Reordena los picks según su champion pool, su winrate por campeón y su forma reciente."
- S2. Base. Chosen option: "Fork de DraftGap (recomendado)" — "Reutiliza su app para Mac, sus datos por parche y la conexión al cliente; añado la personalización dentro."
- S3. Explanation. Chosen option: "Estadística + explicación con LLM" — "Además, un LLM explica cada sugerencia en lenguaje natural. Requiere una clave de API o un modelo local."
- S4. Draft input. Chosen option: "Automática desde el cliente" — "Lee el champ select en vivo por la API local del cliente en su Mac."
- S5. LLM provider. User: "uso qwen 3.8 flash-next de 125b de una cuantización de q2xss creo con strata creo que es rápido y bien." Resolved on this machine: OpenAI-compatible endpoint `https://strata.yusenliu.es/v1`, model id `qwen3.8-flash-next-iq2_xs`. Endpoint, model and key must be configurable; the key is never committed.
- S6. Location. User: "en github en la carpeta /Users/yusenliu/Documents/DEV/Github". Chosen option: "Fork público en GitHub y clon local".
- S7. Without personal history the suggestions must be identical to upstream DraftGap (stated in the approved plan: "sin historial el resultado debe ser idéntico al de DraftGap original").
- S8. Riot policy constraint from the approved plan: "Siempre muestra varias opciones, nunca una orden única"; no automated actions in the client, no memory reading. Amended by S11: writing a rune page and an item set is allowed only on an explicit user click; picking or banning for the user stays forbidden.
- S9. Language. User: "el idioma de las cosas prefiero en español". Chosen option: "Todo (recomendado)" — "Interfaz completa en español, nombres de campeones, objetos y runas en español, y el LLM respondiendo en español."
- S10. Items and runes. User: "que tenga acceso a todos los objetos del juego para recomendar y runas? eso se puede?" A recommended build (runes, items, boots, starters, skills, summoner spells) for the champion and role, from the patch statistics.
- S11. Client import. User: "pero no deja como itero que te lo pone directamente no?" Chosen option: "Sí, con botón" — "Cambia la regla de solo lectura: la app escribe runas y objetos en el cliente solo cuando usted pulsa. Elegir o banear sigue prohibido."
- S12. Account analyzer. User: "el analizador de su cuenta me parece importante". Chosen option: "Lo anterior + tendencias" — "KDA, farmeo por minuto, oro, daño, visión, duración, winrate y forma reciente, a partir del historial del cliente (hasta 200 partidas)." plus "evolución en el tiempo, rachas y comparación con la media del campeón en su elo."
- S13. UI redesign. User: "Ahora si, la interfaz necesita una mejora brutal, hay que mirar como es itero.gg." Chosen: "Interfaz nueva" first, "Maquetas primero (recomendado)" — "Le preparo 2 o 3 direcciones visuales en HTML para que elija antes de tocar la app." Original visual identity: study iTero's information architecture, never copy its brand or look.
- S14. Matchup chat. User: "Necesito también que según mi oponente pueda hablar con la IA y según mi jugador y mi oponente que me explica como jugar con él." Chosen moments: "En la selección" — "Cuando su rival de línea ya ha elegido." and "En la pantalla de carga y partida" — "Con los diez campeones ya conocidos."
- S15. Model. User: "quiero usar el modelo inkling 2 mini para luego fine tuning de los conocimientos en general de lol no tanto de parche de las mejoras o esto que creo que es mejor que el mismo consulte las estadísticas y base de datos no tanto que lo tenga ya en su lógica como itero.gg." Chosen: "En su servidor Strata" — "Lo sirve usted igual que Qwen y la app solo cambia de modelo." Patch data and champion kits come from live data in each request; fine-tuning is a later step.
- S16. Opponent scouting. User: "falta que muestre mis rivales su rango en la ranked y más informaciones no?" Only from the loading screen / in game, where names are visible; never de-anonymize players during ranked champ select.
- S17. Recent form in the rating. Agent proposal accepted by the user ("me parece bien tus recomendaciones"): "añadirla con un peso pequeño y amortiguada cuando hay pocas partidas recientes, igual que ya se hace con el winrate. Así una racha larga se nota y dos partidas malas no cambian nada." S7 still holds: no history or personalization off is identical to upstream.
- S18. Analyzer against the player's own elo. Agent proposal accepted by the user: "la app leería su rango del cliente y pediría a Lolalytics las estadísticas de ese tramo", "con esmeralda+ como respaldo cuando no se pueda leer su rango o no haya datos suficientes en su tramo." The screen must say which baseline is in use.
- S19. Enemy data for the model. User: "falta la función de ver los datos de los enemigos su estadísticas y rango con eso usar el modelo para recomendar también." The scouted rank and recent statistics of the players (S16, in-game phases only) are given to the model in the in-game matchup chat so its advice uses them. S16's privacy rule is unchanged: nothing about other players is requested during champ select.
