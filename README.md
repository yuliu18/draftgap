# DraftGap
DraftGap.com is a site and desktop application which helps you pick and draft your League of Legends team. It suggests champions based on the meta, their matchups with every opponent champion and every ally duo. Its a unopinionated tool using only statistics to make suggestions.

If you ever wondered what champion to pick, which is the best champion you could have picked, or if the game was truly lost in draft, DraftGap is for you.

Find it at [draftgap.com](https://draftgap.com), or download the app, which integrates with the League client to automatically synchronize with the current draft in champ select.

## Riot API key (optional)

To import more of your own match history, sign in at [developer.riotgames.com](https://developer.riotgames.com/) to generate a development key or apply for a personal key. Development keys expire every 24 hours. A personal key is for personal use only, not for running a public service.

In the DraftGap desktop app, open **Settings → Personal → Riot API**, save your key, and leave the League client open and signed in. Choose the number of games and select **Import from Riot**. The key is stored in your OS credential store; you can remove it in the same settings. Local League client sync does not require a Riot API key.
